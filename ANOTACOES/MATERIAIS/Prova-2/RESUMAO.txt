RESUMAO ASSEMBLY AVR (ATmega328P) - CONSULTA PARA PROVA
========================================================

QUERO FAZER...                          VER SECAO
  saber qual flag uma instrucao mexe    3
  escolher ponteiro / modo de acesso    2 e 6
  somar / subtrair 16 ou 32 bits        8
  ordem dos bytes na memoria            7

  erro de montagem / resultado errado   11


--------------------------------------------------------
1. MEMORIA
--------------------------------------------------------
Dados (endereco de 16 bits):
  0x0000-0x001F   registradores R0-R31
  0x0020-0x005F   I/O (endereco de I/O = endereco de dados - 0x20)
  0x0060-0x00FF   I/O estendido
  0x0100-0x08FF   SRAM 2 KB (SRAM_START = 0x0100, RAMEND = 0x08FF)
Flash: 16K palavras de 16 bits (32 KB). Reset comeca em 0x0000.
EEPROM: 1 KB.
Arquitetura load-store: a ULA so opera registradores.
  Memoria: carrega (LD/LDS) -> opera -> guarda (ST/STS).
I/O: SREG = 0x3F, SPH = 0x3E, SPL = 0x3D, PORTB = 0x05, DDRB = 0x04


--------------------------------------------------------
2. REGISTRADORES E PONTEIROS
--------------------------------------------------------
R0-R15   uso geral, NAO aceitam constante (sem LDI)
R16-R31  aceitam constante: LDI CPI SUBI SBCI ANDI ORI SBR CBR SER
R26:R27 = X (XL, XH)   R28:R29 = Y (YL, YH)   R30:R31 = Z (ZL, ZH)

O que cada ponteiro aceita:
          LD/ST   X+  -X   LDD/STD (q=0..63)   LPM
    X      sim    sim sim        NAO             nao
    Y      sim    sim sim        sim             nao
    Z      sim    sim sim        sim             sim

Carregar ponteiro (LOW/HIGH = metades do ENDERECO inicial da variavel):
    LDI XL, LOW(A)
    LDI XH, HIGH(A)

Restricoes:
  ADIW / SBIW   so R24, R26, R28, R30    K = 0..63
  MOVW          so pares (R0, R2, ... R30)
  MUL           resultado em R1:R0
  CLR e TST     funcionam em qualquer registrador


--------------------------------------------------------
3. SREG (FLAGS)
--------------------------------------------------------
  bit:  7  6  5  4  3  2  1  0
        I  T  H  S  V  N  Z  C
  C = carry (soma) ou borrow/emprestimo (subtracao)
  Z = resultado zero      N = negativo (bit 7)
  V = overflow (com sinal)   S = N xor V   H = half carry

Quem mexe em que:
  ADD ADC SUB SBC SUBI SBCI NEG   Z C N V S H
  CP CPC CPI                      igual SUB/SBC, mas NAO grava resultado
  ADIW SBIW                       Z C N V S      (MEXE no C!)
  INC DEC                         Z N V S        (NAO mexe no C)
  AND ANDI OR ORI EOR             Z N V=0 S
  COM                             Z N V=0 C=1
  MUL                             Z C
  LDI MOV MOVW LD LDS LDD ST STS STD PUSH POP IN OUT   nenhuma flag
  (OUT SREG altera as flags de proposito)

SBC/CPC mantem o Z: so fica Z=1 se este byte E o anterior deram zero.


--------------------------------------------------------
4. DIRETIVAS E TEMPLATE
--------------------------------------------------------
  .INCLUDE <m328Pdef.inc>   nomes do chip (SPH, RAMEND, SRAM_START...)
  .DSEG / .CSEG / .ESEG     SRAM / Flash (codigo) / EEPROM
  .ORG end                  endereco de origem
  .BYTE n                   reserva n bytes na SRAM (NAO inicializa)
  .DB / .DW                 bytes / words constantes na Flash
  .DEF nome = Rn            apelido de registrador
  .EQU nome = expr          constante fixa      .SET = constante redefinivel
Numeros: 10 | 0x0A ou $0A | 0b00110101 | octal com zero: 010
Operadores: + -  |  LOW(x)  HIGH(x)  (ex.: STS A+1, R16)
Comentario: ; ou //

Template simples:
    .INCLUDE <m328Pdef.inc>
    .DSEG
    .ORG SRAM_START
    A: .BYTE 4
    .CSEG
    .ORG 0x0000
    main:
        ...
    fim:
        RJMP fim

Com sub-rotina (inicializa a pilha):
    main:
        LDI R16, HIGH(RAMEND)
        OUT SPH, R16
        LDI R16, LOW(RAMEND)
        OUT SPL, R16
        ...
    fim:
        RJMP fim


--------------------------------------------------------
5. INSTRUCOES (ciclos no ATmega328P)
--------------------------------------------------------
TRANSFERENCIA
  LDI Rd,K        Rd <- K (R16-R31)                  1
  MOV Rd,Rr       Rd <- Rr                           1
  MOVW Rd,Rr      par <- par                         1
  LDS Rd,k        Rd <- (k)     direto, 2 palavras   2
  STS k,Rr        (k) <- Rr     direto, 2 palavras   2
  LD Rd,X|Y|Z     Rd <- (ponteiro), tambem X+ e -X   2
  ST X|Y|Z,Rr     (ponteiro) <- Rr                   2
  LDD Rd,Y+q      Rd <- (Y+q)   Y ou Z, q=0..63      2
  STD Y+q,Rr      (Y+q) <- Rr                        2
  LPM Rd,Z        le da Flash                        3
  IN Rd,P  OUT P,Rr    I/O <-> registrador           1
  PUSH Rr  POP Rd      pilha                         2

ARITMETICA / LOGICA (todas 1 ciclo, exceto onde indicado)
  ADD  ADC  SUB  SBC  SUBI  SBCI
  ADIW  SBIW (16 bits)                               2
  INC  DEC  AND  ANDI  OR  ORI  EOR
  COM (0xFF-Rd)  NEG (0-Rd)  CLR (=0)  SER (=0xFF)  TST
  CP  CPC  CPI
  MUL                                                2
  LSL LSR ASR ROL ROR SWAP BST BLD
  Nao existe ADDI. Somar constante K:  SUBI Rd, -K

FLUXO
  RJMP rot   relativo                                2
  JMP rot    absoluto                                3
  RCALL rot  chama sub-rotina (relativo)             3
  CALL rot   chama sub-rotina (absoluto)             4
  RET / RETI retorna                                 4
  NOP                                                1

DESVIOS CONDICIONAIS (1 ciclo se nao desvia, 2 se desvia; alcance -64..+63)
  BREQ  Z=1 (igual)          BRNE  Z=0 (diferente)
  BRCS/BRLO  C=1  menor, sem sinal
  BRCC/BRSH  C=0  maior ou igual, sem sinal
  BRLT  S=1  menor, com sinal    BRGE  S=0  maior ou igual, com sinal
  BRMI  N=1                       BRPL  N=0
  BRVS/BRVC  V      BRHS/BRHC  H      BRTS/BRTC  T      BRIE/BRID  I
  SBRC/SBRS Rr,b   pula se bit do registrador = 0 / 1
  SBIC/SBIS P,b    pula se bit de I/O = 0 / 1

BITS DE I/O (so enderecos de I/O 0x00-0x1F, 2 ciclos)
  SBI P,b   liga      CBI P,b   desliga
  .equ LED = PB5 / sbi DDRB,LED (saida) / sbi PORTB,LED / cbi PORTB,LED

SEC (C=1)   CLC (C=0)   SEI / CLI (I)


--------------------------------------------------------
6. OS 5 MODOS DE ENDERECAMENTO DA SRAM
--------------------------------------------------------
  Modo            Sintaxe          Efeito
  1 Direto        LDS Rd,k         Rd <- (k)
                  STS k,Rr         (k) <- Rr
  2 Indireto      LD Rd,X          Rd <- (X)          ponteiro nao muda
                  ST X,Rr          (X) <- Rr
  3 Pos-incr.     LD Rd,X+         Rd <- (X); X++     +1 DEPOIS do acesso
                  ST X+,Rr
  4 Pre-decr.     LD Rd,-X         X--; Rd <- (X)     -1 ANTES do acesso
                  ST -X,Rr
  5 Deslocamento  LDD Rd,Y+q       Rd <- (Y+q)        ponteiro nao muda
                  STD Y+q,Rr       q = 0..63, so Y e Z

Quando usar:
  Direto        1 endereco por byte (LDS A, LDS A+1, ...), repetitivo
  Indireto      ponteiro parado; avanca na mao com INC XL (nao altera o C)
  Pos-incr.     vetores e somas multi-byte; cada bloco fica identico
  Pre-decr.     percorre de tras para frente (comeca no endereco SEGUINTE ao ultimo)
  Deslocamento  um ponteiro so para varios campos (A=Y+0, B=Y+4, C=Y+8)

Variaveis na SRAM:
    .DSEG
    .ORG SRAM_START
    var1: .BYTE 1       ; 0x0100
    var2: .BYTE 2       ; 0x0101 e 0x0102 (2o byte = var2+1)
    var3: .BYTE 1       ; 0x0103
  .BYTE so reserva. O valor entra em codigo: LDI + STS.

Ponteiro e um NUMERO em registradores (nao esta na SRAM).
  Y = 0x0104  ->  YH = 0x01, YL = 0x04
  O "01" do YH e parte do ENDERECO, nao e dado de B.


--------------------------------------------------------
7. LITTLE-ENDIAN
--------------------------------------------------------
Byte MENOS significativo (LSB) no MENOR endereco.

  0x12345678 a partir de 0x0100:

     0x0100  0x0101  0x0102  0x0103      enderecos crescem ->
    +------+------+------+------+
    |  78  |  56  |  34  |  12  |
    +------+------+------+------+
     byte0  byte1  byte2  byte3
     (LSB)                (MSB)
     A      A+1    A+2    A+3

  Dump do simulador: leia da DIREITA para a ESQUERDA.
     78 56 34 12  ->  0x12345678
     FF FF 01 00  ->  0x0001FFFF

  Registradores: R17:R16 = 0x1234  ->  R16 = 34 (LSB), R17 = 12 (MSB)

Gravar: LSB primeiro (STS A, ... STS A+1, ... STS A+2, ... STS A+3, ...)

Por que pos-incremento na soma/subtracao:
  O carry sobe do byte 0 ao byte 3, e X+ anda para o proximo byte mais
  significativo. Pre-decremento (-X) comecaria pelo MSB: ordem errada.


--------------------------------------------------------
8. ARITMETICA 16 E 32 BITS
--------------------------------------------------------
REGRA: 1o byte com ADD/SUB; demais com ADC/SBC.
Entre os blocos so use o que NAO altera o C: LD ST LDS STS LDI MOV INC DEC.
(ADIW, SBIW, ADD, CP estragam o carry.)

Declaracao usada nos modelos:
    .DSEG
    .ORG SRAM_START
    A: .BYTE 4          ; 0x0100-0x0103
    B: .BYTE 4          ; 0x0104-0x0107
    C: .BYTE 4          ; 0x0108-0x010B

--- 8 bits: R18 = R16 + R17 + 22 ---
    MOV  R18, R16
    ADD  R18, R17
    SUBI R18, -22           ; soma 22

--- 16 bits: res = num1 + num2 (pos-incremento) ---
    (.BYTE 2 em cada variavel)
    LDI XL, LOW(num1)
    LDI XH, HIGH(num1)
    LDI YL, LOW(num2)
    LDI YH, HIGH(num2)
    LDI ZL, LOW(res)
    LDI ZH, HIGH(res)
    LD  R16, X+             ; byte baixo
    LD  R17, Y+
    ADD R16, R17
    ST  Z+, R16
    LD  R16, X              ; byte alto (ultimo, sem +)
    LD  R17, Y
    ADC R16, R17
    ST  Z, R16
  Teste: 0x01FF + 0x0001 = 0x0200   (SRAM: 00 02)

--- 32 bits: C = A + B, manual, pos-incremento ---
    LDI XL, LOW(A)
    LDI XH, HIGH(A)
    LDI YL, LOW(B)
    LDI YH, HIGH(B)
    LDI ZL, LOW(C)
    LDI ZH, HIGH(C)
    LD  R16, X+             ; byte 0
    LD  R17, Y+
    ADD R16, R17
    ST  Z+, R16
    LD  R16, X+             ; byte 1
    LD  R17, Y+
    ADC R16, R17
    ST  Z+, R16
    LD  R16, X+             ; byte 2
    LD  R17, Y+
    ADC R16, R17
    ST  Z+, R16
    LD  R16, X              ; byte 3 (sem +)
    LD  R17, Y
    ADC R16, R17
    ST  Z, R16
  Teste: A = 0x0001FFFF, B = 0x00000001 -> C = 0x00020000
    byte | A  | B  | conta       | C  | carry
      0  | FF | 01 | FF+01       | 00 |  1
      1  | FF | 00 | FF+00+1     | 00 |  1
      2  | 01 | 00 | 01+00+1     | 02 |  0
      3  | 00 | 00 | 00+00+0     | 00 |  0
  SRAM: 0x0108=00 0x0109=00 0x010A=02 0x010B=00
  Ponteiros no fim: X=0x0103, Y=0x0107, Z=0x010B

--- 32 bits: mesma soma nos outros modos ---
  DIRETO:
    LDS R16, A    / LDS R17, B    / ADD R16, R17 / STS C,   R16
    LDS R16, A+1  / LDS R17, B+1  / ADC R16, R17 / STS C+1, R16
    LDS R16, A+2  / LDS R17, B+2  / ADC R16, R17 / STS C+2, R16
    LDS R16, A+3  / LDS R17, B+3  / ADC R16, R17 / STS C+3, R16
  INDIRETO (sem +): depois de cada ST avance com INC XL / INC YL / INC ZL.
    Nao use ADIW (altera o C). INC e seguro: o byte baixo 0x00..0x0B nao estoura.
  DESLOCAMENTO (um ponteiro): LDI YL,LOW(A) / LDI YH,HIGH(A)
    LDD R16, Y+0 / LDD R17, Y+4 / ADD R16, R17 / STD Y+8,  R16
    LDD R16, Y+1 / LDD R17, Y+5 / ADC R16, R17 / STD Y+9,  R16
    LDD R16, Y+2 / LDD R17, Y+6 / ADC R16, R17 / STD Y+10, R16
    LDD R16, Y+3 / LDD R17, Y+7 / ADC R16, R17 / STD Y+11, R16

--- 32 bits: C = A - B, manual ---
  Igual a soma, trocando ADD -> SUB e ADC -> SBC:
    LD R16, X+ / LD R17, Y+ / SUB R16, R17 / ST Z+, R16    ; byte 0
    LD R16, X+ / LD R17, Y+ / SBC R16, R17 / ST Z+, R16    ; byte 1
    LD R16, X+ / LD R17, Y+ / SBC R16, R17 / ST Z+, R16    ; byte 2
    LD R16, X  / LD R17, Y  / SBC R16, R17 / ST Z,  R16    ; byte 3
  Teste: A = 0x12345678, B = 0x00117799 -> C = 0x1222DEDF
    byte | A  | B  | conta       | C  | carry
      0  | 78 | 99 | 78-99       | DF |  1
      1  | 56 | 77 | 56-77-1     | DE |  1
      2  | 34 | 11 | 34-11-1     | 22 |  0
      3  | 12 | 00 | 12-00-0     | 12 |  0
  Na subtracao, C = 1 significa "pediu emprestado" (borrow).

--- 32 bits: C = A - B, com loop ---
  Byte 0 fora do loop (SUB gera o carry), bytes 1 a 3 dentro (SBC).
    (X, Y, Z carregados como nos modelos acima)
    LD   R16, X+            ; byte 0 fora do loop
    LD   R17, Y+
    SUB  R16, R17           ; gera o Carry (borrow)
    ST   Z+, R16
    LDI  R18, 3             ; faltam 3 bytes
  lp:
    LD   R16, X+
    LD   R17, Y+
    SBC  R16, R17           ; usa o Carry do byte anterior
    ST   Z+, R16
    DEC  R18                ; DEC nao mexe no C
    BRNE lp                 ; BRNE usa o Z do DEC
  Soma com loop: igual, trocando SUB -> ADD e SBC -> ADC.
  O ultimo ST Z+ avanca o Z uma vez a mais; e inofensivo.
  Contador com DEC (e nao SUBI), porque SUBI mexeria no Carry.

--- 32 bits: var_A = var_A + 1 ---
  INC NAO propaga vai-um. Use ADD no byte 0 e ADC com zero nos demais.
    LDI XL, LOW(var_A)
    LDI XH, HIGH(var_A)
    LDI R18, 1              ; valor somado ao byte 0
    CLR R19                 ; zero, so para propagar o Carry
    LD  R16, X
    ADD R16, R18            ; byte 0
    ST  X+, R16
    LD  R16, X
    ADC R16, R19            ; byte 1
    ST  X+, R16
    LD  R16, X
    ADC R16, R19            ; byte 2
    ST  X+, R16
    LD  R16, X
    ADC R16, R19            ; byte 3
    ST  X, R16
  Teste: 0x00FFFFFF + 1 = 0x01000000   (SRAM: 00 00 00 01)

--- 16 bits em registradores ---
  R17:R16 + R19:R18 :   ADD R16, R18   /   ADC R17, R19
  Somar constante em ponteiro: ADIW Z, 4   (K = 0..63)


--------------------------------------------------------
9. PILHA E SUB-ROTINAS
--------------------------------------------------------
Pilha: area da SRAM para enderecos de retorno e dados temporarios.
Cresce para BAIXO (de RAMEND = 0x08FF para menores enderecos).
SP = SPH:SPL. No 328P ja nasce em RAMEND, mas inicialize sempre:
    LDI R16, HIGH(RAMEND)
    OUT SPH, R16
    LDI R16, LOW(RAMEND)
    OUT SPL, R16

  Instrucao              SP       Efeito
  PUSH Rr                SP - 1   poe 1 byte
  CALL / RCALL / ICALL   SP - 2   poe endereco de retorno (2 bytes)
  POP Rd                 SP + 1   tira 1 byte
  RET / RETI             SP + 2   tira endereco de retorno

PUSH/POP e LIFO: desempilhe na ordem INVERSA.
    PUSH R16
    PUSH R17
    POP  R17
    POP  R16

Rotulo x sub-rotina:
  Rotulo: so marca um ponto; desvia com RJMP/BRxx; nao volta sozinho.
  Sub-rotina: comeca num rotulo, TERMINA COM RET; chamada por RCALL/CALL;
  volta para a instrucao seguinte a chamada.
    main:
        RCALL minha_sub
        RJMP main
    minha_sub:
        ...
        RET

Salvar contexto (se a sub-rotina altera registradores do chamador):
  PUSH no inicio, POP no fim. Para o SREG:
    IN R17, SREG / PUSH R17 ... POP R17 / OUT SREG, R17
Parametros: passe por registradores (X/Y/Z apontando variaveis, R16-R19 com valores).

Sub-rotinas de 32 bits (o main carrega ponteiros/valores antes do RCALL):
  ; init_32bits: X = destino; R16..R19 = bytes (R16 = LSB)
  init_32bits:
      ST X+, R16
      ST X+, R17
      ST X+, R18
      ST X,  R19
      RET

  ; zera_32bits: X = variavel
  zera_32bits:
      CLR R16
      ST X+, R16
      ST X+, R16
      ST X+, R16
      ST X,  R16
      RET

  ; sub_32bits: X = A, Y = B, Z = C  ->  C = A - B
  sub_32bits:
      LD  R16, X+
      LD  R17, Y+
      SUB R16, R17
      ST  Z+, R16
      LD  R16, X+
      LD  R17, Y+
      SBC R16, R17
      ST  Z+, R16
      LD  R16, X+
      LD  R17, Y+
      SBC R16, R17
      ST  Z+, R16
      LD  R16, X
      LD  R17, Y
      SBC R16, R17
      ST  Z, R16
      RET
  As sub-rotinas alteram R16/R17 e os ponteiros: o main recarrega X/Y/Z
  antes de cada chamada.


--------------------------------------------------------
10. ATRASO (DELAY)
--------------------------------------------------------
Entrada: R19.  R19 = 16 -> ~200 ms | R19 = 80 -> ~1 s (a 16 MHz)
    delay:
        PUSH R17
        PUSH R18
        IN   R17, SREG
        PUSH R17            ; salva as flags
        CLR  R17
        CLR  R18
    loop:
        DEC  R17            ; comeca em 0 -> 256 voltas
        BRNE loop
        DEC  R18
        BRNE loop
        DEC  R19
        BRNE loop
        POP  R17
        OUT  SREG, R17      ; restaura as flags
        POP  R18
        POP  R17
        RET
  R19 e o parametro: nao e salvo e volta zerado.
  Se R19 = 0, o DEC vira 0xFF e roda 256 vezes (atraso enorme).

Uso (LED em PB5):
    .equ LED = PB5
        SBI DDRB, LED       ; PB5 como saida
    main:
        SBI PORTB, LED
        LDI R19, 16
        RCALL delay
        CBI PORTB, LED
        LDI R19, 16
        RCALL delay
        RJMP main

Conta de tempo:
  ATRASO = ciclos / f_CPU          (16 MHz -> periodo 62,5 ns)
  DEC = 1 ciclo; BRNE = 2 se desvia, 1 se nao desvia.
  Laco interno (R17 de 0): 255 x (1+2) + (1+1) = 767 ciclos
  Cada unidade de R19 ~ 197 119 ciclos ~ 12,32 ms
  R19 = 16 -> ~197 ms      R19 = 80 -> ~985 ms
  Laco simples:  LDI R16,N / l: DEC R16 / BRNE l   ->   3N ciclos
  RCALL = 3 ciclos, RET = 4 ciclos (somam no total, se o enunciado pedir).


--------------------------------------------------------
11. ARMADILHAS
--------------------------------------------------------
 1. LDI so em R16-R31. "LDI R5, 3" da erro.
 2. INC/DEC NAO mudam o C. ADIW/SBIW MUDAM. No meio de soma multi-byte,
    avance ponteiro com INC XL, nunca com ADIW.
 3. INC nao propaga vai-um: em 32 bits use ADD/ADC.
 4. 1o byte ADD/SUB, demais ADC/SBC. Se um laco comeca em ADC/SBC, faca CLC antes.
 5. X NAO tem LDD/STD. So Y e Z (q = 0..63).
 6. .BYTE so reserva; inicialize em codigo (LDI + STS/ST).
 7. LOW()/HIGH() sao do endereco INICIAL da variavel (.BYTE 4 nao entra).
 8. Ultimo byte: use o ponteiro SEM "+" (X, nao X+) se quiser que ele
    termine no ultimo byte da variavel.
 9. Pos-incremento comeca no 1o byte; pre-decremento comeca no endereco
    seguinte ao ultimo.
10. Todo PUSH precisa de POP (ordem inversa) antes do RET.
11. Sem RET no fim da sub-rotina, a execucao escorrega para o codigo seguinte.
12. BRNE olha o Z do ultimo resultado: nao ponha ADD/CP entre o DEC e o BRNE.
13. LDI e de 8 bits: constante de 16 bits = dois LDI (HIGH e LOW).
14. Sem sinal: BRLO/BRSH (usam C). Com sinal: BRLT/BRGE (usam S).
15. SBI/CBI so em I/O baixo (0x00-0x1F). PORTB e DDRB ok.
16. Nao use LD R26, X+ (destino igual ao ponteiro: resultado indefinido).
