1. Subtração de 16 bits com pós-incremento
Calcule C = A - B, com A = 0x0300 e B = 0x0101, usando X, Y e Z com LD X+, LD Y+ e ST Z+.
Resultado esperado: C = 0x01FF, ou seja, SRAM FF 01.
Conferir: o Carry vale 1 depois do byte 0, e esse empréstimo é usado no byte 1.

.INCLUDE <m328Pdef.inc>

.DSEG
.ORG 0x0100

A:.BYTE 2
B:.BYTE 2
c:.BYTE 2

.CSEG
.ORG 0x0000

sub_16bits_pos_incremento:
    ; C = A-B
    
    LDI XL, LOW(A)
    LDI XH, HIGH(A)
    LDI YL, LOW(B)
    LDI YH, HIGH(B)
    LDI ZL, LOW(C)
    LDI ZH, HIGH(C)
    
    ; PRIMEIRO BYTE
    LD R16, X+
    LD R17, Y+
    SUB R16,R17
    ST Z+, R16
    
    ; SEGUNDO BYTE
    LD R16, X
    LD R17, Y
    SBC R16,R17
    ST Z, R16
    
fim:
    rjmp fim

2. Soma de 32 bits com um único ponteiro (deslocamento)
Calcule C = A + B, com A = 0x00FFFFFF e B = 0x00000001. Use só o ponteiro Y (apontando para A) com LDD/STD, sem mexer em Y.
Resultado esperado: C = 0x01000000, ou seja, SRAM 00 00 00 01.
Perguntas: quais valores de q você usou para A, B e C? Y terminou em qual endereço?

.INCLUDE <m328Pdef.inc>

.DSEG
.ORG 0x0100

A:.BYTE 4
B:.BYTE 4
c:.BYTE 4

.CSEG
.ORG 0x0000

soma_32_bits_ptr_unico_deslocamento:
    ; C = A-B
    
    LDI YL, LOW(A)
    LDI YH, HIGH(A)
    
    ; PRIMERIO BYTE
    LDD R16, Y+0
    LDD R17, Y+4
    ADD R16,R17
    STD Y+8 , R16
    
    ; SEGUNDO BYTE
    LDD R16, Y+1
    LDD R17, Y+5
    ADC R16,R17
    STD Y+9, R16
    
    ; TERCEIRO BYTE
    LDD R16, Y+2
    LDD R17, Y+6
    ADC R16,R17
    STD Y+10, R16
    
    ; QUARTO BYTE
    LDD R16, Y+3
    LDD R17, Y+7
    ADC R16,R17
    STD Y+11, R16
    
fim:
    rjmp fim

3. Soma de um vetor com laço
Declare um vetor V: .BYTE 5 com os valores 100, 200, 150, 250 e 50, e RES: .BYTE 2. Some todos os elementos num resultado de 16 bits, 
com laço, contador em registrador (DEC + BRNE) e LD X+.
Resultado esperado: RES = 0x02EE (750), ou seja, SRAM EE 02.
Armadilha do exercício: a soma estoura 8 bits, então o byte alto precisa receber o carry com ADC e um registrador zerado.

.INCLUDE <m328Pdef.inc>

.DSEG
.ORG 0x0100
V:   .BYTE 5 ; GUARDAR OS VALORES
RES: .BYTE 2 ; VARIÁVEL QUE VAI SOMAR

.CSEG
.ORG 0x0000

main:
    LDI XL, LOW(V)
    LDI XH, HIGH(V)
    
    LDI R16, 0x05 ; CONTADOR i 
    
    ; GARANTE OS ZEROS NOS REGISTRADORES
    ; VAMOS USAR ELES PARA AS SOMAS
    CLR R17             
    CLR R18             
    CLR R19             

    ; CHAMA O LOOP 
    RCALL loop_soma

    ; SALVAR O RESULTADO NA MEMÓRIA
    STS RES, R17        
    STS RES+1, R18      

fim:
    RJMP fim

loop_soma:
    LD R20, X+          
    ADD R17, R20  ; se passar de 255, vai ativar o carry 
    ADC R18, R19  ; soma com carry caso esteja ativado 
    
    DEC R16             
    BRNE loop_soma      
    RET

4. Inverter um vetor com pré-decremento
Com V: .BYTE 4 = 11 22 33 44, copie para W: .BYTE 4 na ordem inversa. Leia V com LD R16, X+ e grave em W com ST -Y, R16, começando com Y em W+4.
Resultado esperado: W = 44 33 22 11 (do menor para o maior endereço).
Perguntas: por que o Y começa em W+4 e não em W+3? Qual é o valor de Y no final?

.INCLUDE <m328Pdef.inc>

.DSEG
.ORG 0x0100

ORIGINAL:   .BYTE 4 ; GUARDAR OS VALORES
INVERTIDO: .BYTE 4 ; VARIÁVEL QUE VAI SOMAR

.CSEG
.ORG 0x0000

inverter_array:
    ; PREPARAR OS PONTEIROS
    ; APONTA PARA O ORIGINAL
; APONTA PARA O FINAL DO ORIGINAL (já que vamos ler com -X)
    LDI XL, LOW(ORIGINAL+4)
    LDI XH, HIGH(ORIGINAL+4)
    
    ; APONTA PARA O INÍCIO DO INVERTIDO (já que vamos gravar com Y+)
    LDI YL, LOW(INVERTIDO)
    LDI YH, HIGH(INVERTIDO)
    
    ; PRIMEIRO BYTE
    LD R16, -X
    ST Y+, R16
    
   ; SEGUNDO BYTE
    LD R16, -X
    ST Y+, R16
    
    ; TERCEIRO BYTE
    LD R16, -X
    ST Y+, R16
    
   ; QUARTO BYTE
    LD R16, -X
    ST Y+, R16 
    
fim: 
    rjmp fim
